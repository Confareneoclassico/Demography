# What Demographic Prediction Can and Cannot Achieve: A Global Sensitivity Analysis of Structural Risk in Population Projections

Data and scripts for the study:

> Lo Piano, S. et al. "What Demographic Prediction Can and Cannot Achieve: A Global Sensitivity Analysis of Structural Risk in Population Projections." *Risk Analysis* (under review).

This repository applies Global Sensitivity Analysis (GSA) and the Modelling of the Modelling Process (MoMP) framework to two demographic case studies: (1) a retrospective analysis of the optimisation-based model used to underpin China's one-child policy (Song et al.), and (2) a multi-model projection of global population to 2050 and 2075.

## Data

The scripts require two input files in the `data/` directory:

**1. UN World Population Prospects 2024**
Download `WPP2024_GEN_F01_DEMOGRAPHIC_INDICATORS_COMPACT.xlsx` from:
https://population.un.org/wpp/downloads?folder=Standard%20Projections&group=CSV%20format

Place it at `data/WPP2024_GEN_F01_DEMOGRAPHIC_INDICATORS_COMPACT.xlsx`.

**2. Combined world population time series**
`world_population_combined_1950_2100.csv` is provided in the `data/` folder of this repository. It combines UN historical estimates (1950–2023) and medium-variant projections (2024–2100).

## Running the code

### Case study 1 — Song et al. model (China)

```bash
python Song.py
```

Runs 256 Monte Carlo simulations (Sobol' quasi-random sequences) perturbing eight demographic and optimisation parameters. Outputs:

- `figures/uncertainty_distributions.png` — histograms of key output variables
- `figures/population_trajectories.png` — ensemble of population trajectories
- `figures/fertility_trajectories.png` — ensemble of fertility trajectories
- `results/simulation_results.csv` — full simulation output table

Expected runtime: ~5–15 minutes depending on hardware.

### Case study 2 — MoMP global projection

```bash
python MoMP_world.py
```

Runs 1,024 Monte Carlo simulations across four demographic models (Cohort-Component, UN WPP, Lee-Carter, Lotka-Volterra) and eight uncertain parameters. Outputs:

- `figures/scatter_2050_<param>.png` / `figures/scatter_2075_<param>.png` — scatter plots per input parameter
- `results/simulation_results_actual.csv` — full simulation output table
- `results/sobol_results.txt` — Sobol' first-order and total-order sensitivity indices

Expected runtime: ~10–30 minutes depending on hardware.

