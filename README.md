# What Demographic Prediction Can and Cannot Achieve: A Global Sensitivity Analysis of Structural Risk in Population Projections

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23344949.svg)](https://doi.org/10.5281/zenodo.23344949)

Data and scripts for the study

> Lo Piano, S., Kuc-Czarnecka, M., Pielke Jr., R. and Saltelli, A. "What Demographic Prediction Can and Cannot Achieve: A Global Sensitivity Analysis of Structural Risk in Population Projections." *Risk Analysis* (revised version under review, 2026).

The repository applies global sensitivity analysis and the modelling of the modelling process to two case studies: (1) a retrospective sensitivity audit of the optimal-control model of Song et al. that underpinned China's one-child policy, and (2) a multi-model projection of world population to 2050 and 2075 comparing cohort-component sub-models with an aggregate ARIMA paradigm.

## Requirements

Python 3.10 or later. Install the dependencies with `pip install -r requirements.txt`.

## Reproducing the results

Both case studies use the Saltelli design with N(k+2) runs for k inputs, giving first-order and total-order Sobol' indices. Optimal-transport indices are computed on the same samples.

**Case study 1, Song et al. model (k = 8, N = 512, 5,120 optimal-control solves, a few minutes on two cores).**

```bash
SALTELLI_N=512 python Song_control_audit.py   # solves, metrics, Sobol' and OT indices, figures
python song_robustness.py                      # bootstrap intervals (1,000 resamples), convergence grid
python song_book_check.py                      # checks against Song, Tuan and Yu (1985), Table 8.14 and others
```

The model follows Song, Tuan and Yu (1985), *Population Control in China: Theory and Applications*, chapter 8: the discrete population equation (2.2-13), the performance index (8.4-2), the stationary target of 700 million (8.2-1 to 8.2-3) and the three state constraints of Program 1 (peak population at most 1.2 billion, dependency index at most 1, aging index at most 0.7), with fertility bounded in [1, 2.16]. Data tables are transcribed from the book (Tables 2.5, 2.10, 2.12, 3.3 and 6.1).

`RESUME=1` restarts an interrupted run from the last completed solve. Outputs carry the suffix `_saltelli`.

**Case study 2, global experiment (k = 10, N = 2048, 24,576 runs, under a minute).**

```bash
python MoMP_world.py         # runs, summary statistics, Sobol' and OT indices, Figure 4
python momp_robustness.py    # bootstrap intervals (1,000 resamples), convergence, OT intervals
```

## Results

`results/` holds the outputs from which the paper's tables and figures are drawn, so that every reported number can be checked without rerunning:

- Song audit: `song_control_audit_saltelli.csv` (run-level inputs and control-path metrics of the 5,120 solves), `song_control_trajectories_saltelli.npz` (fertility and population trajectories), `song_control_stats_saltelli.csv`, `song_control_sensitivity_saltelli.json`, `song_robustness.json`, `song_book_check.json` (comparison with the book)
- Global experiment: `simulation_results_v2.csv` (24,576 runs), `momp_v2_summary.json`, `sobol_v2_2050.txt`, `sobol_v2_2075.txt`, `momp_robustness.json`

`figures/` is regenerated by the scripts and not tracked. `Song.py` also contains the plain-design analysis of the submitted version (`python Song.py`, 256 runs).

## Data provenance

`Data/wpp2024_world_2023_single_age.csv` is extracted from the `wpp2024` R data package (version 1.1-3, github.com/PPgp/wpp2024), world aggregate (code 900): population by single age and sex on 1 July 2023 (`popAge1dt`, mean of the end-of-year values for 2022 and 2023, which reproduces WPP's 1 July total of 8,091.7 million), death rates by single age and sex in 2023 (`mx1dt`) and the percentage age pattern of fertility in 2023 (`percentASFR1dt`). Populations are in thousands.

## Corrections disclosed in the revision

The submitted version contained an error in the Lotka branch, which passed the both-sex fertility schedule to the Euler-Lotka equation and inflated the implied growth rate. Lotka is no longer part of the design. The commit history preserves the earlier code.

Corrections made after the resubmission (November 2026) are listed in `CHANGELOG.md`.
